Kiến Trúc Tích Hợp

Cơ Chế Khám Phá & Tiết Lộ Lũy Tiến

Google Antigravity được thiết kế để duy trì token context tinh gọn nhất có thể. Dưới đây là cách hệ thống quét và kích hoạt kỹ năng từ Vietnam Agentic Skills.

1

Ưu Tiên Workspace

Antigravity ưu tiên tìm trong thư mục .agents/skills/ của dự án đang mở. Bạn cài skill vào dự án nào thì dự án đó được phục vụ.

2

Progressive Disclosure

Chỉ có tiêu đề và mô tả trong YAML frontmatter được đọc khi khởi động. Nội dung chi tiết chỉ nạp khi câu lệnh của bạn cần đến, tiết kiệm 99% chi phí token.

3

Zero-NPX Native Symlink

Lệnh --mode link tạo symbolic link tương đối, không tốn dung lượng ổ đĩa và tự động đồng bộ khi cập nhật catalog.

Bắt Đầu Nhanh

Cài Đặt & Sử Dụng Sau 3 Bước

BƯỚC 1

Tải kho lưu trữ về máy

git clone https://github.com/huytran1120/vietnam-agentic-skills.git
cd vietnam-agentic-skills
chmod +x vas vas.py
BƯỚC 2

Cài đặt kỹ năng vào dự án Antigravity của bạn

# Cài đặt vào workspace hiện tại (dạng link tương đối, siêu nhẹ):
./vas install docker-security --target workspace --mode link

# Cài đặt toàn cục cho Antigravity (dùng ở mọi dự án):
./vas install 007 --target global
