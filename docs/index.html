Giải Đáp Thắc Mắc

Câu Hỏi Thường Gặp (FAQ)

Tôi dùng OpenAI Codex thì có cần cài Node.js hay npx không? ↓

Hoàn toàn không. Toàn bộ hệ thống quản lý VAS chạy 100% bằng Python 3 tích hợp sẵn qua ./vas. Codex tự động đọc định dạng chuẩn Open Agent Skills và chạy script native trong terminal của bạn.

Cơ chế Progressive Disclosure tiết kiệm token như thế nào? ↓

AI Agent chỉ quét phần tóm tắt ngắn (YAML frontmatter gồm name và description) lúc mở phiên. Chỉ khi câu hỏi hoặc task của bạn liên quan đến chuyên môn của skill đó, agent mới nạp toàn bộ runbook và script chi tiết vào context window.

Tôi có thể cài đặt một skill cho nhiều AI Coding Assistant cùng lúc không? ↓

Chỉ cần dùng cờ --target all (ví dụ: ./vas install ui-ux-pro-max --target all). Hệ thống sẽ tự động tạo symlink vào toàn bộ các thư mục của Antigravity, Codex, Claude Code, Cursor, Windsurf, Cline và Copilot CLI.
