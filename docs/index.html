Giải Đáp Thắc Mắc (FAQ)

Câu Hỏi Thường Gặp Về Vietnam Agentic Skills

Mọi điều bạn cần biết về việc tích hợp và tối ưu hoá kỹ năng cho các AI Coding Agents.

1. Vietnam Agentic Skills (VAS) hỗ trợ những AI Coding Agent nào? ▼

VAS tương thích toàn diện với: Google Antigravity, OpenAI Codex / OpenCode, Claude Code, Cursor IDE, Windsurf (Codeium), Cline / Roo Code, và GitHub Copilot CLI. Nhờ tuân theo chuẩn mở agentskills.io, các playbook SKILL.md không có bất kỳ rào cản nền tảng nào.

2. Tôi dùng OpenAI Codex thì có cài đặt được không? ▼

Hoàn toàn được và chạy cực kỳ hiệu quả! Bạn chỉ cần chạy lệnh: ./vas install <skill_id> --target codex. Codex có khả năng đọc Markdown, hiểu rõ cấu trúc step-by-step và gọi trực tiếp các script Python/Bash có sẵn trong từng kỹ năng.

3. Làm sao để cài đặt một kỹ năng cho tất cả các AI Tool cùng lúc? ▼

Bạn chỉ cần chạy lệnh: ./vas install <skill_id> --target all. Công cụ sẽ tự động tạo symlink vào toàn bộ thư mục nhận diện của Antigravity, Codex, Claude, Cursor, Windsurf, Cline và Copilot trong workspace.

4. Tại sao VAS lại sử dụng kiến trúc Zero-NPX? ▼

Zero-NPX giúp loại bỏ hoàn toàn việc phụ thuộc vào runtime Node.js/npm nặng nề. Toàn bộ CLI được viết bằng Python 3 thuần có sẵn trên macOS/Linux/Windows, giúp tra cứu và cài đặt kỹ năng offline tức thì chỉ dưới 0.05 giây mà không lo lỗi mạng hay rủi ro bảo mật từ các remote package bên ngoài.

5. Cơ chế Progressive Disclosure tiết kiệm token như thế nào? ▼

Thay vì nạp toàn bộ hàng ngàn dòng tài liệu vào bộ nhớ của AI gây quá tải và hallucinate, các AI Agent chỉ quét qua phần tóm tắt ngắn (frontmatter). Khi bạn đặt câu hỏi cụ thể liên quan, AI mới tự động mở và đọc toàn bộ hướng dẫn chuyên sâu, giúp tiết kiệm tới 99% chi phí token ngữ cảnh.
